Gutenberg Prints the Bible

c. AD 1455

In Mainz, Johannes Gutenberg used movable metal type to print the Latin Vulgate in a run of perhaps 180 copies on paper and vellum, of which about 49 survive. The 42-line Bible was the first major book printed with movable type in Europe, and the press it launched would carry Scripture and reform across the continent.
