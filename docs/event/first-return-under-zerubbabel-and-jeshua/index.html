First Return under Zerubbabel and Jeshua

536 BC

After Cyrus's decree, about 42,000 exiles led by Zerubbabel and the priest Jeshua go up from Babylon to Judah, carrying back the temple vessels that Nebuchadnezzar had taken. Sheshbazzar, the prince of Judah, receives the vessels. The return is the first step in restoring worship at Jerusalem.
